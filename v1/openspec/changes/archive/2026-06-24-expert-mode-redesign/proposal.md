# Proposal: 专家模式重构

## 问题

当前专家模式实现存在以下问题：
- 放在 Bot 设置里，应该是一个临时的输入框旁开关
- 三轮 API 调用的过程不可见（用户只看到闪烁的光标）
- 草稿纸内容不可见
- 专家模式会丢失 Bot 人格（已修复但架构不对）
- 不够"帅"——看不到思考过程

## 目标

将专家模式从 Bot 设置重构为输入框旁的临时开关，发送消息时可选择是否使用专家模式。专家模式的三轮思考过程实时展示在 AI 消息气泡内，草稿纸可查看。

## 设计要点

1. **入口**：输入框右侧增加 🎯 按钮，点击高亮 = 开启（仅对下一条消息生效）
2. **消息气泡内展示**：
   - Stage 1/2/3 各自作为一个可展开的区块
   - 每个 Stage 显示进度状态（进行中/完成）
   - 草稿纸可点击查看
   - 最终结论在最下方
3. **后端**：每完成一个 Stage 就向前端推送该 Stage 的内容（而非等全部完成）
4. **Bot 设置**：移除专家模式开关（改为临时开关）

## 范围

- `web/index.html`：移除 bot 编辑器中的专家模式设置，输入框旁增加按钮
- `web/js/chat.js`：专家模式发送逻辑、Stage 渲染、草稿纸浮层
- `web/style.css`：Stage 区块样式、草稿纸浮层样式
- `backend/expert_mode.py`：重构为逐 Stage 推送模式
- `backend/api.py`：移除 bot 设置中的专家模式逻辑
