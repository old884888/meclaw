```
┌──────────────────────────────────────────────────────────┐
│  [💬 对话] [💻 编程]   [🧑‍💻 代码助手 ▾]   [█████░░]  [⚙] [🗑] │
```

当前模式高亮（琥珀金色），另一个灰色可点击。

### 3.2 切换行为

| 从 → 到 | 行为 |
|---------|------|
| 对话 → 编程 | 弹出文件夹选择（如果还没有工作目录），切换到三栏布局 |
| 编程 → 对话 | 切换回单栏布局 |
| 编程 → 编程（不同目录） | 弹出文件夹选择，重新加载文件树和项目概览 |

**关键规则：**
- 两个模式**共享同一个 Bot 和同一个会话**，对话连续
- 切换模式不创建新会话，不丢失任何对话
- 工作目录信息存在会话级别
- **read_files 在模式切换时保持不变**，只在会话关闭或「新任务」时清空
- 切到对话模式后，文件树和预览面板隐藏但状态保留，切回来时恢复

### 5.2 项目概览自动生成

后端扫描项目目录，为每个文件生成一行摘要。

**摘要生成规则（基于结构特征，不是前 3 行）：**

```python
import re
import os

SKIP_DIRS = {'.git', 'node_modules', '__pycache__', '.venv', 'venv',
             'dist', 'build', '.meclaw_backup', '.idea', '.vscode',
             '.next', '.nuxt', 'target', 'bin', 'obj'}
BINARY_EXTS = {'.exe', '.dll', '.png', '.jpg', '.jpeg', '.gif', '.mp4',
               '.zip', '.tar', '.gz', '.woff', '.woff2', '.ttf', '.ico',
               '.pdf', '.mp3', '.wav', '.avi', '.mov', '.so', '.dylib'}
MAX_FILES = 50
MAX_OVERVIEW_TOKENS = 1000  # 约 2000 字符（中文）或 4000 字符（英文）

def quick_summary(filepath, ext, head_content):
    """基于文件名 + 扩展名 + 结构特征生成一句话摘要"""
    basename = os.path.basename(filepath)

    if ext == '.py':
        classes = re.findall(r'^class\s+(\w+)', head_content, re.M)
        funcs = re.findall(r'^(?:def|async def)\s+(\w+)', head_content, re.M)
        if 'if __name__' in head_content:
            return f"入口文件，函数 {', '.join(funcs[:3])}" if funcs else "入口文件"
        if classes:
            return f"类 {', '.join(classes[:3])}"
        if funcs:
            return f"函数 {', '.join(funcs[:3])}"
        return "Python 模块"

    if ext in ('.js', '.ts', '.jsx', '.tsx'):
        exports = re.findall(r'export\s+(?:default\s+)?(?:class|function|const)\s+(\w+)', head_content)
        if exports:
            return f"导出 {', '.join(exports[:3])}"
        return f"{'TypeScript' if ext in ('.ts', '.tsx') else 'JavaScript'} 模块"

    if ext == '.json':
        if basename == 'package.json':
            return "Node.js 项目配置"
        if basename in ('tsconfig.json', 'jsconfig.json'):
            return "编译器配置"
        return "JSON 数据文件"

    if ext == '.md':
        return "文档"

    if ext in ('.html', '.htm'):
        return "HTML 页面"

    if ext == '.css':
        return "样式文件"

    if ext in ('.yaml', '.yml'):
        return "YAML 配置"

    if ext in ('.sh', '.bash', '.ps1', '.bat'):
        return "脚本文件"

    if ext == '.sql':
        return "SQL 脚本"

    if ext == '.go':
        funcs = re.findall(r'^func\s+(?:\(\w+\s+\*?\w+\)\s+)?(\w+)', head_content, re.M)
        return f"函数 {', '.join(funcs[:3])}" if funcs else "Go 模块"

    if ext == '.rs':
        return "Rust 模块"

    if ext in ('.toml', '.ini', '.cfg', '.conf'):
        return "配置文件"

    return f"{ext.lstrip('.')} 文件" if ext else "文本文件"


def generate_project_overview(folder_path):
    """生成项目索引概览，控制在 1000 token 以内"""
    lines = []
    total_files = 0

    for root, dirs, files in os.walk(folder_path):
        dirs[:] = [d for d in dirs if d not in SKIP_DIRS and not d.startswith('.')]

        rel_root = os.path.relpath(root, folder_path)
        if rel_root == '.':
            rel_root = ''

        for fname in sorted(files):
            ext = os.path.splitext(fname)[1].lower()
            if ext in BINARY_EXTS:
                continue

            total_files += 1
            filepath = os.path.join(root, fname)
            rel_path = os.path.join(rel_root, fname) if rel_root else fname

            try:
                with open(filepath, 'r', encoding='utf-8') as f:
                    head = f.read(4000)  # 读前 4000 字符用于结构分析
                    total_lines = head.count('\n') + 1
                    summary = quick_summary(filepath, ext, head)
                    lines.append(f"{rel_path} ({total_lines}行) - {summary}")
            except (UnicodeDecodeError, PermissionError):
                lines.append(f"{rel_path} - (二进制/无法读取)")

    # 限制条目数
    if len(lines) > MAX_FILES:
        lines = lines[:MAX_FILES]
        lines.append(f"... 共 {total_files} 个文件，仅显示前 {MAX_FILES} 个")

    # 截断到 token 预算
    overview = "项目结构概览：\n" + '\n'.join(lines)
    if len(overview) > 4000:  # ~1000 token
        overview = overview[:4000] + "\n... (概览已截断)"

    return overview
```

### 6.3 Diff 预览生成

**后端生成 unified diff**，前端渲染为红绿高亮：

```python
import difflib

def generate_diff(old_content, new_content, filepath):
    """生成 unified diff 文本"""
    old_lines = old_content.splitlines(keepends=True)
    new_lines = new_content.splitlines(keepends=True)
    diff = difflib.unified_diff(old_lines, new_lines,
                                 fromfile=f"a/{filepath}",
                                 tofile=f"b/{filepath}",
                                 lineterm='')
    return ''.join(diff)
```

`file:edit` 执行时，后端先备份原内容，再写入新内容，同时生成 diff 一并返回给前端。

## 七、编程模式上下文管理

### 7.1 核心原则

**文件内容不进对话历史（conversationHistory）。** 文件上下文由独立的 `ReadFilesManager` 管理。

### 7.2 上下文分层与 Token 预算优先级

发送给 API 的 messages 按以下顺序组装，**优先级从高到低**：

```
优先级 1（固定）：System Prompt
  ├── 灵魂文件夹（soul.md + constraints.md + memory.md + knowledge/）
  ├── 已启用技能指令
  ├── 文件操作指引
  └── 编程模式专属指令（含项目概览）

优先级 2（有就占）：压缩摘要（5-10%）

优先级 3（弹性）：文件上下文（预算 30%，超了自动移除最早的文件）

优先级 4（弹性）：最近 N 轮对话（填充剩余空间，按轮数从旧到新截断）

优先级 5（预留）：用户新消息 + AI 回复空间（预留 ≥ 20%）
```

**超预算时的让步规则：**
- 文件上下文超 30% → 移除最早的文件（ReadFilesManager._trim）
- 对话历史超出剩余空间 → 按轮数从旧到新截断
- System Prompt 和回复空间不让步

### 7.3 ReadFilesManager

```python
import json

class ReadFilesManager:
    """管理编程模式下读取的文件上下文（内存中，不持久化）"""

    def __init__(self, max_tokens=8000):
        self.files = {}           # {path: content}
        self.read_order = []      # 按读取顺序
        self.max_tokens = max_tokens
        self.snapshots = {}       # {msg_id: snapshot}，内存快照
        self.max_snapshots = 20   # 快照上限

    def add_file(self, path, content):
        """添加或更新文件，语义去重：同路径只保留最新版本"""
        if path not in self.files:
            self.read_order.append(path)
        self.files[path] = content
        self._trim()

    def get_context_messages(self):
        """返回当前文件上下文，组装为单条 system 消息"""
        if not self.files:
            return []

        file_blocks = []
        for path in self.read_order:
            content = self.files[path]
            file_blocks.append(f"--- {path} ---\n```\n{content}\n```")

        body = "以下是当前已读取的文件内容，供你参考：\n\n" + '\n\n'.join(file_blocks)
        return [{"role": "system", "content": body}]

    def get_snapshot(self):
        """返回当前状态快照"""
        return {
            "files": dict(self.files),
            "read_order": list(self.read_order)
        }

    def save_snapshot(self, msg_id):
        """保存快照（带上限控制）"""
        self.snapshots[msg_id] = self.get_snapshot()
        # 超过上限移除最早的
        while len(self.snapshots) > self.max_snapshots:
            oldest_key = next(iter(self.snapshots))
            del self.snapshots[oldest_key]

    def restore_snapshot(self, msg_id):
        """恢复到指定快照"""
        if msg_id in self.snapshots:
            snap = self.snapshots[msg_id]
            self.files = dict(snap["files"])
            self.read_order = list(snap["read_order"])
            # 清除此快照之后的所有快照
            keys = list(self.snapshots.keys())
            idx = keys.index(msg_id)
            for k in keys[idx + 1:]:
                del self.snapshots[k]

    def total_chars(self):
        """当前文件上下文总字符数"""
        return sum(len(c) for c in self.files.values())

    def get_info(self):
        """返回文件列表和使用量，供前端状态面板显示"""
        return {
            "files": [
                {"path": p, "chars": len(self.files[p])}
                for p in self.read_order
            ],
            "total_chars": self.total_chars(),
            "total_tokens_est": self.total_chars() // 2,
            "max_tokens": self.max_tokens
        }

    def _trim(self):
        """超预算时移除最早的文件"""
        while self.total_chars() // 2 > self.max_tokens and len(self.read_order) > 1:
            oldest = self.read_order.pop(0)
            del self.files[oldest]

    def clear(self):
        self.files.clear()
        self.read_order.clear()
        self.snapshots.clear()
```

**关键设计说明：**
- 快照只存内存，**不写磁盘**（会话重新打开时 read_files 为空）
- 快照上限 20 条，超出移除最早的
- get_context_messages 返回**单条 system 消息**，不伪造 user/assistant 对
- 会话关闭后重新加载时，文件上下文丢失，用户需要重新指示 AI 读取文件

```python
def build_messages_for_api(self):
    """组装发送给 API 的完整 messages"""
    messages = []

    # 第 1 层：System Prompt（灵魂 + 技能 + 文件指引 + 编程概览）
    messages.append({"role": "system", "content": self.build_system_prompt()})

    # 第 2 层：压缩摘要（如果有）
    if self.summary:
        messages.append({"role": "system", "content": f"[对话摘要]\n{self.summary}"})

    # 第 3 层：文件上下文（编程模式）
    if self.mode == "code" and self.read_files:
        messages.extend(self.read_files.get_context_messages())

    # 第 4 层：最近 N 轮对话
    history = self.get_recent_history()
    messages.extend(history)

    # 第 5 层：用户新消息
    messages.append({"role": "user", "content": user_input})

    return messages
```

**注意：文件上下文放在压缩摘要之后、对话历史之前。** 这样模型先看到文件，再看到对话中的讨论，逻辑更连贯。

### 7.6 编码处理

```python
def safe_read_file(filepath):
    """安全读取文件，自动检测编码"""
    try:
        with open(filepath, 'r', encoding='utf-8') as f:
            content = f.read()
        return content, 'UTF-8'
    except UnicodeDecodeError:
        try:
            import chardet
            with open(filepath, 'rb') as f:
                raw = f.read()
            detected = chardet.detect(raw)
            enc = detected['encoding'] or 'latin-1'
            return raw.decode(enc, errors='replace'), enc
        except ImportError:
            # chardet 不可用时 fallback
            with open(filepath, 'r', encoding='latin-1') as f:
                content = f.read()
            return content, 'latin-1'
```

| .go | go |
| .rs | rust |
| .java | java |
| .c / .cpp | cpp |
| .toml / .ini | ini |

未知扩展名不应用高亮，以纯文本显示。

### 8.4 大文件处理

| 行数 | 处理 |
|------|------|
| < 500 | 完整渲染 |
| 500-2000 | 完整渲染，顶部提示「大文件，渲染可能较慢」 |
| > 2000 | 只渲染前 2000 行，底部提示「文件过大，仅显示前 2000 行。AI 读取不受影响。」 |
| > 50KB | 截断，与现有逻辑一致 |

### 9.1 两步策略

**第一步：进入编程模式时自动生成项目索引**

```
选择文件夹 → 扫描目录 → 生成概览 → 注入 system prompt → AI 知道项目全貌
```

**第二步：AI 按需读取文件**

```
AI 分析概览 → 输出 file:read 标记 → 后端读取并注入 read_files → 前端显示记录块 + 打开预览
```

### 9.2 编程模式 system prompt

```
你现在处于编程模式。用户的项目目录是 {working_dir}。

{project_overview}

编程规则：
1. 读取文件时使用 file:read:path=文件路径，不要在对话中直接粘贴文件内容
2. 修改文件时使用 file:edit:path=文件路径 标记，输出完整的新文件内容
3. 创建文件时使用 file:create:path=文件路径 标记
4. 删除文件时使用 file:delete:path=文件路径 标记
5. 先理解项目结构和现有代码，再进行修改
6. 每次修改前先读取相关文件，确认当前内容
7. 修改后简要说明改了什么、为什么改
```

**概览不进 conversationHistory**，只在构建 API 请求时拼入 system prompt。每次请求都重新生成（因为概览依赖 system prompt 拼接，不依赖会话存储）。

## 十一、对话回退

### 11.1 入口

每条消息 hover 时右上角显示 `[↩]` 按钮。

### 11.2 确认弹窗

```
┌─────────────────────────────────────┐
│  ↩ 回退到此处                        │
│─────────────────────────────────────│
│                                     │
│  将移除之后的 N 条消息，              │
│  涉及 X 个文件操作。                  │
│  回退的消息不会丢失，将保存到          │
│  _rollback/ 目录。                   │
│                                     │
│  [取消]                  [确认回退]  │
└─────────────────────────────────────┘
```

### 11.3 执行流程

```
点击 [↩] → 弹出确认 → 用户确认 →
  1. 将被移除的消息保存到 _rollback/{session_id}/{timestamp}.json
  2. 从 conversationHistory 中移除该条及之后的所有消息
  3. read_files 恢复到该条消息时的快照
  4. 移除该快照之后的所有快照
  5. 前端更新对话窗口
```

### 11.4 read_files 快照时机

- 每次 AI 回复完成后（所有文件操作执行完毕后），调用 `read_files.save_snapshot(msg_id)`
- 回退时调用 `read_files.restore_snapshot(msg_id)`
- 快照只存内存，不持久化到 JSON（会话重新打开时 read_files 为空）
