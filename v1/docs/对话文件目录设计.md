# 对话文件目录设计（v1）

## 目标

AI 通过 `file:send` 从编程工作区复制出来的文件，按**对话**隔离存放，避免所有对话混在同一个扁平目录里。

## 目录结构

```
{对话文件根目录}/                 ← 设置里配置的「文件接收目录」，默认 MeClaw/downloads/
├── 202506041335_a1b2c3d4/      ← 对话 ID（与 history/{id}.json 一致）
│   └── files/                   ← 该对话中 AI 发送的文件
│       ├── report.pdf
│       └── chart.png
├── 202506041408_f9e8d7c6/
│   └── files/
│       └── notes.md
└── ...
```

| 路径 | 说明 |
|------|------|
| `history/{id}.json` | 对话文字记录（原有逻辑，不变） |
| `{根}/{id}/files/` | 该对话的附件/发送文件 |

## 与旧版差异

- **旧版**：所有文件直接落在根目录 `downloads/`，靠时间戳区分同名文件。
- **新版**：根目录下按 `对话ID` 分文件夹，文件进入 `{ID}/files/`。
- **旧文件**：已落在根目录扁平层的文件**不自动迁移**；新发送的文件走新结构。

## 行为约定

1. **保存**：`process_file_sends` 仅在存在 `current_session_id` 时写入 `{根}/{当前ID}/files/`。
2. **删除对话**：删除会话时同步删除 `{根}/{ID}/` 整个目录（含 `files`）。
3. **设置页**：「浏览」设置的是**根目录**；「打开目录」打开根目录，可看到各对话子文件夹。
4. **侧边栏**：「📁」打开**当前对话**的 `files` 目录（无当前对话时提示）。
