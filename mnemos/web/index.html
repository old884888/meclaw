MNEMOS 使用说明书

1. 快速上手流程

  1. 右上角 设置 → 供应商：填写 Base URL、API Key、模型列表，点 测试 确认连通。
  2. 首页点 Bot 卡片 编辑：绑定供应商、选主模型；可选后台模型与AI 超级大脑覆盖。
  3. 点击 Bot 进入对话 → + 新建对话 → 发送消息，流式回复即表示链路正常。

2. 核心概念

  • 供应商：平台级 API 配置（URL / Key / 模型列表），多个 Bot 可共用。
  • Bot：独立人格（Soul）、约束、模型与AI 超级大脑策略；记忆数据按 Bot 隔离在 souls/{bot_id}/memory/。
  • 主模型：用户可见的主对话模型。
  • 后台模型：摘要、L1 记忆提取等后台任务；留空则继承主模型。

3. AI 超级大脑编排（每轮按需激活）

开启后，系统不会每轮塞满所有模块，而是按意图与配置分层注入上下文，节省 token。

  • 执行脑：主对话流式回复（始终参与）。
  • 右脑：人格 / 用户画像片段（Persona）。
  • 记忆脑：召回 L0–L3 与会话摘要相关记忆。
  • 左脑：规划 / 实现类问题按需注入（关键词触发）。
  • 学习脑：后台收集信号，供后续学习迭代（默认关闭）。

全局 设置 → AI 超级大脑 为平台默认；Bot 编辑里可单独覆盖开关与预算。

4. 记忆分层（个人对话向）

  • L0：原始轮次证据（每轮写入）。
  • L1：原子记忆（偏好 / 事实 / 约束 / 待办），可每轮 LLM 或启发式提取。
  • L2：会话级摘要（周期性更新）。
  • L3：用户长期画像（低频聚合）。

5. 上下文压缩（Tier 1–3）

  1. Tier 1：超长单条消息裁剪。
  2. Tier 2：历史消息替换为占位引用（保护最近对话区）。
  3. Tier 3：触发增量 LLM 运行摘要，用摘要 + 保护区消息重建 API 上下文。

阈值与保护区在 设置 → AI 超级大脑 调整；后台摘要走 Bot 的 后台模型。

6. 单轮对话流程

  1. 用户发消息 → 写入会话历史。
  2. 编排器合并全局 + Bot 配置，按开关组装 system 块（人格 / 记忆 / 左脑）。
  3. 压缩引擎评估上下文压力，必要时 Tier3 摘要。
  4. 主模型流式回复。
  5. 回合结束后异步：L0 写入、L1 提取、L2 周期摘要、学习脑信号（若开启）。

7. 首页 Bot 卡片提示

  • 摘要行显示后台模型与 M/P/C 预算（记忆 / 人格 / 左脑）。
  • 默认：继承平台AI 超级大脑设置；已覆盖：该 Bot 有自定义项。
  • 点击 badge 可查看覆盖详情与默认值对比，并快捷进入编辑。

8. 数据与备份

本地数据默认在 meclaw2/data/：config.json、history/、souls/。

设置 → 数据 可导出 ZIP 备份（含密钥，请妥善保管）。

9. 常见问题

  • 不能聊天：检查 Bot 是否绑定供应商并选了有效模型。
  • 供应商测试无反应：确认服务已重启；测试会 toast 提示，卡片上也会显示结果。
  • 记忆未生效：确认AI 超级大脑已开启，且记忆检索/写入开关为开。
  • 端口占用：关闭旧 python 进程后重新运行 启动MNEMOS.bat。
