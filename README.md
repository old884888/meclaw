# MeClaw

一个本地优先的 AI 对话助手，两代实现放在同一个仓库里。

自己填 API Key，不依赖任何托管服务，所有对话与记忆都存在本机。

---

## 两代

| | 形态 | 后端 | 入口 |
|---|---|---|---|
| **[v1/](v1/)** | 桌面应用（pywebview 原生窗口） | `backend/` 拆成 18 个模块 | `启动MeClaw.bat` |
| **[mnemos/](mnemos/)** | 浏览器 Web 应用 | `backend/main.py` + `domain/` 分层 | `启动MNEMOS.bat`（:8766） |

**两人代数据互不通用**，各自独立运行、各自配置 key，可以同时装、同时跑。

---

## 共同点

- 多角色：每个 Bot 一份人设（`.md`）+ 独立记忆库
- 多供应商：配置数组存多组 Base URL / Key / 模型，可给不同角色分配不同大脑
- 长期记忆：本地持久化，带 token 预算与压缩策略
- 联网搜索：函数调用方式接入

## 不同点

| 能力 | v1 | mnemos |
|---|---|---|
| 群聊 | ✅ | ❌ |
| 专家模式 / 专家议会 | ✅ | ❌ |
| 代码模式 | ✅ | ❌ |
| 分层记忆（L1/L2/L3） | ❌ | ✅ |
| 向量语义检索 | ❌ | ✅（fastembed，可选） |
| 话题聚类 / 记忆固化 | ❌ | ✅ |
| 按角色选模型 | ❌ | ✅ |
| 技能机制 | 提示词注入 | 提示词注入 + 技能召回 |
| 测试套件 | — | 140 项 |

## 隐私

- 两个项目默认都只监听 `127.0.0.1`
- API Key 与会话数据全部本地明文存储
- 仓库已排除所有运行时数据：`config.json`、`history/`、`souls/*/memory/`、`data/`
- 只提供 `config.example.json` 模板，首次运行自行生成配置
