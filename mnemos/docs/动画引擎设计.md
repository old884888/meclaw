# MNEMOS 动画引擎设计

MNEMOS 前端动画统一由 **Animation Engine** 管理。业务层只负责编排（何时调用），动画细节全部收敛在 `web/animations/`。

## 设计原则

1. **统一入口**：一律 `AnimEngine.run(id, element, action, options)`。
2. **按序号扩展**：A01、A02、A03… 每个动画独立文件注册。
3. **无障碍**：支持 `prefers-reduced-motion: reduce` 降级（`reduced()` 分支）。
4. **业务不复制动画细节**：`app.js` 只决定何时 `run`，不写 transition 字符串。
5. **能复用则不新建**：同一套 enter/exit 逻辑用 `options.variant` / `options.direction` 区分场景。
6. **多属性 transition 须等主属性结束**：使用 `AnimEngine.waitTransition(el, propertyName, duration)`，避免 `transitionend` 过早触发导致掉帧。

## 目录结构

```
meclaw2/web/animations/
├── engine.js                 # 注册表 + AnimEngine.run() + waitTransition()
├── a01-card-expand.js        # A01 面板展开/收起（历史 Knowledge 用）
├── a02-sibling-reveal.js     # A02 网格聚焦 dim / restore（历史 Knowledge 用）
├── a03-session-insert.js     # A03 列表行 / 网格卡片 入场与退场
├── a04-screen-transition.js    # A04 全屏视图切换（首页 ↔ 聊天）
├── a05-modal-sheet.js        # A05 弹窗（Glass）入场与退场
├── a06-button-press.js       # A06 按钮点击反馈（tap）
├── a07-settings-tab.js       # A07 设置页 Tab 切换
└── （后续动画按序号追加）
```

`index.html` 加载顺序（在 `app.js` 之前）：

```html
<script src="/static/animations/engine.js"></script>
<script src="/static/animations/a03-session-insert.js"></script>
<script src="/static/animations/a04-screen-transition.js"></script>
<script src="/static/animations/a05-modal-sheet.js"></script>
<script src="/static/animations/a06-button-press.js"></script>
<script src="/static/animations/a07-settings-tab.js"></script>
<script src="/static/app.js"></script>
```

## A04 · Screen Transition（全屏视图切换）

**序号：** A04  
**element：** 带 `.anim-screen` 的根视图（`#view-home`、`#view-chat-workspace`）  
**时长：** 360ms · `cubic-bezier(0.32, 0.72, 0, 1)`

### 方向（direction）

| direction | 场景 | exit（离开视图） | enter（进入视图） |
|-----------|------|------------------|-------------------|
| `forward` | 首页 → 聊天 | 左移淡出 + 微缩放 | 右侧滑入 + 淡入 |
| `back` | 聊天 → 首页 | 右移淡出 + 微缩放 | 左侧滑入 + 淡入 |

### 调用示例

```javascript
// 并行切换（业务层 animateScreenChange）
shell.classList.add("is-screen-transitioning");
await Promise.all([
  AnimEngine.run("A04", homeEl, "exit", { direction: "forward" }),
  AnimEngine.run("A04", chatEl, "enter", { direction: "forward" }),
]);
shell.classList.remove("is-screen-transitioning");
```

### 业务编排

```
点击 Bot 进入
    ├─ loadSessions + renderSessionList
    └─ animateScreenChange("chat")  ──► A04 forward

点击「← 返回首页」
    ├─ renderLauncher
    └─ animateScreenChange("home")  ──► A04 back
```

## A03 · Item Reveal（列表行 / 网格卡片）

**序号：** A03  
**element：** `.session-item` 或 `.bot-tile`  
**时长：** 320ms

### 变体（variant）

| variant | enter | exit |
|---------|-------|------|
| `list` | 高度展开 + 淡入 + 上滑 | max-height / margin 收起 + 淡出 + 微缩放（GPU 友好） |
| `card` | 缩放 + 淡入 | 缩放 + 淡出 |

**删除会话优化：** exit 完成后先从 DOM `remove()` 再调 DELETE，避免动画结束后整表重绘造成跳帧。

## A05 · Modal Sheet（Glass 弹窗）

**序号：** A05  
**element：** `.modal`（内部包含 `.modal-panel`）  
**时长：** 300ms

### 行为

| action | 效果 |
|--------|------|
| `enter` | 遮罩淡入 + 面板 `translateY(22px) scale(0.965)` → 正常 |
| `exit` | 遮罩淡出 + 面板 `translateY(16px) scale(0.975)` |

### 业务编排

`app.js` 通过 `showModal(modal)` / `hideModal(modal)` 统一调用 A05。  
目前 Bot 编辑弹窗在「新建 Bot 打开」「取消」「关闭」「保存后关闭」均使用 A05。

---

## A06 · Button Press（按钮点击反馈）

**序号：** A06  
**element：** 按钮 DOM 节点  
**时长：** 180ms

### 行为

| action | 效果 |
|--------|------|
| `tap` | `scale(1)` → `scale(0.94)` → `scale(1)`，带轻微亮度变化 |

### 业务编排

`app.js` 通过 `runButtonTapAnim(button)` 调用 A06。  
当前 Bot 编辑弹窗的「保存 Bot」「取消」按钮已接入 A06。

---

## A07 · Settings Tab（设置页 Tab 过渡）

**序号：** A07  
**element：** `#tab-providers`、`#tab-data`  
**时长：** 220ms

### 行为

| action | 效果 |
|--------|------|
| `enter` | 轻微下滑 + 淡入 |
| `exit` | 轻微上滑 + 淡出 |

### 业务编排

`app.js` 的 `switchTab()` 在切换设置页 Tab 时调用 A07，  
并配合固定高度滚动容器（`settings-tab-stage`）避免内容突变引起弹窗尺寸跳变。

---

## 新增动画流程

1. 新建 `web/animations/aXX-名称.js` 并 `AnimEngine.register`
2. 在 `index.html` 引入（`engine.js` 之后、`app.js` 之前）
3. 更新本文 **动画目录** 与专章
4. 多属性 transition 必须使用 `AnimEngine.waitTransition`
