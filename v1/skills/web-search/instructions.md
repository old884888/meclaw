# 联网搜索

启用后 MeClaw 会：

1. 在系统消息中注入 **北京时间（本机时钟）** — 「今天」必须以该日期为准，禁止臆造 2024/2025 等旧日期。
2. 注册 **search_web** 函数；需要时效信息时调用，查询词应包含系统给出的当前日期。可多轮 refine query（搜 → 思考 → 再搜），受设置中的轮次上限约束。
3. 天气类问题会走 wttr.in；其它默认 **Bing 本地抓取**（无需 Key），可改 DuckDuckGo 或 SerpAPI。

## 回答要求（重要）
- 检索无结果时如实说明「未检索到有效来源」，勿编造、勿把失败演成骂网络
- 引用检索结果并说明检索时间

## 适用场景
- 天气、新闻、价格、版本号等会变化的信息

## 不适用
- 纯代码、数学、上下文已足够的问题
