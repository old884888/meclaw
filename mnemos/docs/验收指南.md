# MNEMOS 验收指南

当你准备测试时，按此清单逐项验收。每项通过打 ✓。

## 启动

1. 双击 `启动MNEMOS.bat`，在菜单中选 **[1] 启动服务**
2. **保持该 CMD 窗口打开**；关闭窗口或按 Ctrl+C 会停止后端
3. 若关窗后仍能访问，说明旧进程仍在跑 → 双击 `停止MNEMOS.bat`，或启动菜单选 **[2] 停止服务**
4. 需要换代码后重载 → `重启MNEMOS.bat`，或菜单 **[3] 重启服务**
5. 浏览器应自动打开 `http://127.0.0.1:8766`
6. 页面标题为 **MNEMOS**，界面为浅色卡片风格

## 1. 配置供应商（必做）

1. 点右上角 **设置**
2. **供应商** Tab → 填写 Base URL、API Key、模型
3. 点 **保存供应商** → **测试** 应显示连接成功
4. **机器人** Tab → 确认 Bot 已绑定该供应商

## 2. 聊天（Chat）

1. 左侧选 Bot → **+ 新建对话**
2. 输入一条消息并发送
3. 应看到流式回复
4. 刷新页面后历史仍在

## 3. 导入资料（Knowledge 基础）

1. 点 **导入** → 选 **文本**
2. 粘贴一段资料（100 字以上）→ **开始整理**
3. 应显示生成的知识卡片（标题、分类、摘要）
4. 切到 **Knowledge** → 能看到卡片列表

## 4. URL 导入（可选）

1. **导入** → **链接** → 粘贴一个文章 URL
2. 成功后卡片应带来源；失败会保留 URL 与错误信息

## 5. 问知识库

1. 在 **Knowledge** 页输入问题 → **提问**
2. 回答区应显示答案 + **来源列表**

## 5b. 知识卡片交互

1. 点击卡片 → 下方 **详情槽** 展开（A01），网格内卡片尺寸不变
2. 其余卡片轻微变暗（A02 focus），不应出现整行跳动或闪屏
3. 再次点击同一卡片 → 详情槽收起（A01）+ 网格恢复（A02 restore）
4. 展开后点 **查看 L0 原文** → 详情槽内显示原文
5. 动画规范见 [动画引擎设计.md](动画引擎设计.md)（A01 面板 + A02 网格聚焦）

## 6. 分层记忆（Memory）

1. **设置 → 记忆** → 开启：
   - 启用记忆系统
   - 聊天前检索相关知识
   - 对话后写入 L0 证据
   - 知识检索策略：先用 `hybrid`
   - 记忆注入检索策略：先用 `hybrid`
2. 保存后回到 **Chat**，问与已导入资料相关的问题
3. 回答应能引用知识库内容
4. **Memory** 页应看到 L0 / L1 列表
5. 点 **一键聚合 L2+L3** → L2、L3 层应有条目
6. 在 **Knowledge** 再提问一次，回答区应显示「检索策略：hybrid」

## 7. Wiki

1. 打开 **Wiki** → 应看到页面卡片与交互式关系图
2. 在关系图中：
   - 拖拽节点可调整位置
   - 滚轮可缩放，空白处拖拽可平移画布
   - 点击节点应高亮相关连线，并打开下方 **Wiki 页面**
3. 在 Wiki 页面中：
   - Markdown 正文应正常渲染（标题、列表、代码等）
   - 点击 `[[交叉引用]]` 或「相关页面」芯片可跳转
   - Knowledge 卡片详情里点「在 Wiki 中打开」应跳转到对应页面
4. 点 **适应画布** / **重置视图** 可调整视图
5. 点 **重建 Wiki** 可刷新图谱

## 8. 数据备份

1. **设置 → 数据** → 应显示本地数据目录路径
2. 点 **导出备份 ZIP** → 浏览器应下载 `mnemos-backup-*.zip`
3. 解压后应包含 `data/config.json`、`data/knowledge/` 等目录

## 9. 持久化

1. 双击 `停止MNEMOS.bat` 停止服务（或启动菜单 **[2]**）
2. 再次双击 `启动MNEMOS.bat` 并选 **[1] 启动**
3. 配置、对话、知识卡片、Memory 数据应仍在

## 数据位置

默认：`meclaw2/data/`

- `config.json` — 配置与 API Key（本地明文，请自行备份）
- `knowledge/notes/` — L1 知识卡片
- `knowledge/raw/` — L0 原文
- `memory/l0/` — 对话证据
- `memory/l2/`、`memory/l3/` — 主题块与画像
- `wiki/graph.json` — 关系图

## 常见问题

| 问题 | 处理 |
|------|------|
| `python` 找不到 | 用 `启动MNEMOS.bat`，不要手打 python |
| 关 CMD 后仍能访问 / 端口占用 | 双击 `停止MNEMOS.bat`；或 `启动MNEMOS.bat` → **[2] 停止** |
| 改代码后要 reload | `重启MNEMOS.bat` 或菜单 **[3] 重启** |
| 不能聊天 | 先配置供应商并让 Bot 绑定 |
| 导入失败 | 确认 API Key 有效；URL 抓取失败可改贴文本 |
| 记忆不生效 | 设置里开启 memory 三个开关 |

验收完成后，可将本清单结果反馈给开发者。
